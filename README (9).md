# IRIX NORMA

Нормативная себестоимость производства пищевых добавок по выгрузкам из 1С:УНФ.

Одна HTML-страница. Ничего не устанавливается, сервер не нужен, данные никуда не уходят — весь расчёт идёт в браузере.

---

## Что делает

Разворачивает спецификацию изделия до сырья, подставляет закупочные цены и считает себестоимость единицы продукции. Дальше сопоставляет её с продажами и показывает маржу — по позициям, по покупателям и в разбивке до каждого компонента банки.

- Калькуляция: количество, выручка, себестоимость за единицу и итого, маржа в рублях и процентах
- Состав изделия: дерево до сырья с ценой, суммой и долей каждого компонента
- Покупатели: выручка, себестоимость и маржа в разрезе контрагентов
- Цены сырья: что осталось без цены, выгрузка списка и загрузка заполненного обратно
- Отчёт: убыточные позиции, неполные расчёты, сырьё без цен, продажи без спецификации

## Запуск

Скачайте `index.html` и откройте в браузере двойным щелчком. Это всё.

Для публикации в интернете — раздел [Публикация на GitHub Pages](#публикация-на-github-pages) ниже.

## Какие файлы загружать

Три выгрузки из 1С:УНФ в формате xlsx, без ручной правки.

| Файл | Отчёт 1С | Что нужно в нём |
|---|---|---|
| Спецификации | Универсальный отчёт «Спецификации по умолчанию» | Номенклатура, Состав.Номенклатура, Состав.Количество, Состав.Ед. |
| Цены закупок | Анализ закупок | Номенклатура, Цена |
| Продажи | Реализация товаров | Номенклатура, Количество, Выручка; покупатели вложенными строками |

Колонки определяются по названиям в шапке, а не по их порядку, поэтому перестановка столбцов в настройках отчёта разбор не ломает. Шапка может занимать две строки — 1С часто объединяет ячейки по вертикали, это учтено.

Порядок загрузки любой. Спецификации обязательны, остальное можно добавить позже.

## Как считается себестоимость

**Рекурсия по составу.** Компонент, у которого есть своя спецификация, раскрывается дальше. Глубина ограничена восемью уровнями, циклические ссылки перехватываются и показываются как ошибка данных, а не роняют расчёт.

**Выход партии.** Рецептура смеси задана на партию: «103 кг креатина», а в банку идёт 0,3 кг. Стоимость партии делится на её выход. Для сыпучих и жидких смесей выход считается как сумма заложенного сырья — по закону сохранения массы. Для наборов из штучных деталей (банка, крышка, ложка, этикетка) деления нет, выход равен единице. Значение можно задать вручную, если фактический выход отличается от расчётного.

**Варианты рецептуры.** У одной номенклатуры в 1С бывает несколько спецификаций — разные вкусы, фасовки, редакции СГР. Складывать их нельзя, поэтому они хранятся раздельно, а считается один выбранный вариант. Выбор виден в калькуляции и меняется на вкладке «Состав изделия».

**Цена сырья.** Сначала своя цена, введённая руками, затем закупочная. Если цены нет ни там, ни там, позиция не превращается в ноль: она помечается, а расчёт получает статус «неполный» с указанием, чего не хватает.

**Что в себестоимость не входит:** зарплата, накладные расходы, амортизация, налоги. Считается только сырьё и упаковка, поэтому «маржа» здесь — маржинальная прибыль, а не рентабельность.

## Сопоставление названий

В продажах и спецификациях одна позиция часто названа по-разному: «Joyer premium "5-НТР"…» и «СТМ "5-НТР" (ТЖК)». На вкладке «Сопоставление» такие позиции собраны вместе, к каждой предложены похожие спецификации с оценкой близости. Связали один раз — связка сохраняется и применяется при каждом следующем расчёте.

Услуги и прочее, что не производится (разработка рецептуры, сертификация, подготовка к маркетплейсам), отмечается как непроизводимое и перестаёт числиться в ошибках.

## Где хранятся данные

Цены, введённые вручную, связки названий, отметки непроизводимых позиций и выбранные варианты рецептуры сохраняются в localStorage браузера. На сервер ничего не отправляется.

Отсюда два следствия. Данные привязаны к конкретному браузеру на конкретном компьютере. Чистка кеша их удаляет.

Поэтому на вкладке «Загрузка» есть резервная копия: «Сохранить всё в файл» выгружает JSON, «Восстановить из файла» возвращает обратно. Сохраняйте копию перед обновлением приложения и перед чисткой браузера.

## Публикация на GitHub Pages

Файл приложения должен называться **`index.html`** и лежать в корне репозитория — тогда он откроется по адресу вида `https://username.github.io/repo-name/` без указания имени файла.

1. Создайте репозиторий и положите в него `index.html` и этот `README.md`
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`
3. Через минуту страница будет доступна по адресу из того же раздела

**Если хочется оставить осмысленное имя файла.** Положите приложение под любым именем, например `norma.html`, и добавьте рядом `index.html` с перенаправлением:

```html
<!DOCTYPE html>
<meta charset="utf-8">
<meta http-equiv="refresh" content="0; url=norma.html">
<title>IRIX NORMA</title>
<a href="norma.html">Открыть IRIX NORMA</a>
```

**Если приложений в репозитории несколько.** Разложите по папкам, в каждой свой `index.html`:

```
/index.html          — страница со ссылками на приложения
/norma/index.html    — себестоимость добавок
/cost/index.html     — себестоимость мебели
```

Адреса получатся `…/norma/` и `…/cost/`.

Важно: перед заливкой новой версии выгрузите резервную копию данных. Публикация файла её не тронет, но привычка полезная.

## Требования

Актуальные версии Chrome, Edge, Yandex Browser. Экран от 1366 пикселей по ширине.

Чтение xlsx выполняет библиотека SheetJS, она подгружается с CDN — при первом открытии нужен интернет. Дальше приложение работает и без сети, пока вкладка открыта. Если нужна полная автономность, вставьте библиотеку в файл вместо ссылки на CDN.

---

## Известные ограничения

- Единицы измерения не пересчитываются между собой. Если полуфабрикат заложен в изделие в штуках, а его рецептура составлена в килограммах, узел помечается предупреждением «единицы не сходятся» — такие случаи нужно править в 1С.
- Циклические ссылки в спецификациях перехватываются, но расчёт по такой ветке будет неполным. Цикл видно в отчёте.
- Нет учёта потерь и технологического брака: считается, что заложенное сырьё полностью переходит в продукцию.
- Себестоимость только материальная, см. выше.

## Диагностика

Если что-то пошло не так, откройте консоль браузера (F12). При каждой загрузке туда пишется распознанная раскладка файла, номера колонок, число прочитанных строк и время разбора. Ошибки разбора дополнительно показываются прямо в карточке файла.
